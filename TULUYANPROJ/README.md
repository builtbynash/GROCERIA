# PAMILIHUB

**Java Foundations Final Project**

PAMILIHUB is a Java-based grocery store management application developed using Java Swing. It provides a graphical user interface that allows users to interact with a grocery store system, manage products, handle shopping cart items, and process customer orders.

The project demonstrates fundamental Java programming concepts, including conditional statements, ArrayList, exception handling, and object-oriented programming.

## Features

- Graphical User Interface (GUI) using Java Swing
- Product management
- Shopping cart management
- Order processing
- Product and cart item handling
- Conditional statements for program logic
- Exception handling for invalid inputs and errors

## Classes

| **Class** | **Description** |
|---|---|
| `Main` | Entry point of the application. |
| `Product` | Represents grocery products and their related information. |
| `CartItem` | Represents individual products added to the shopping cart. |
| `Order` | Handles order-related information and processing. |
| `GroceryStore` | Manages the grocery store's main operations and functionality. |

## Programming Concepts Used

- **If-Else Statements** – Used for conditional logic and decision-making.
- **ArrayList** – Used for storing and managing collections of data.
- **Try-Catch** – Used for exception handling and preventing unexpected program crashes.
- **Object-Oriented Programming (OOP)** – Uses classes and objects to organize the application's structure.
- **Java Swing** – Used to build the graphical user interface.

## How to Run

1. Install JDK 17 or later.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Make sure Java extensions are installed in VS Code.
5. Open `src/Main.java` and run the application.
